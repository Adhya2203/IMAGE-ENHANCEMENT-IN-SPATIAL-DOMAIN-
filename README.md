# Image Enhancement in Spatial Domain

## Introduction

This repository contains MATLAB implementations of three commonly used image enhancement techniques in the spatial domain. These programs were developed to understand how pixel-level operations improve image quality.

## Programs Included

- Histogram Equalization
- Median Filtering
- Laplacian Image Sharpening

## Software Used

- MATLAB

## Applications

- Image enhancement
- Noise removal
- Contrast improvement
- Edge enhancement
- Digital image processing
